# Trading Bot Dashboard (Streamlit)

This project is a Python-based Streamlit application that displays
forex trading data using interactive dashboards.

## Features
- Forex data visualization
- Interactive charts
- Dashboard using Streamlit

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## How to Run the Project
1. Clone the repository
2. Install requirements:
   pip install -r requirements.txt
3. Run the app:
   streamlit run dashboards.py
