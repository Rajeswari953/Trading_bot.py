# Trading Data Analysis Dashboard

## Live Dashboard
https://tradingbotpy-r84ibnw5iedumz6jnk9mhn.streamlit.app

## Project Overview
This project is an interactive trading data analysis dashboard built using Python and Streamlit. It visualizes market data and helps in understanding price trends and basic trading behavior.

## Problem Statement
Understanding market trends and price movements from raw trading data can be complex. Without proper visualization, it is difficult to identify patterns and make informed decisions.

## Solution
This dashboard provides a simple and interactive way to explore trading data, visualize trends, and simulate basic buy/sell conditions based on predefined logic.

## Tools & Technologies Used
- Python
- Streamlit
- Pandas
- Data Visualization

## Dataset
- Forex trading dataset (CSV)

## Key Features
- Visualization of price trends
- Interactive data exploration
- Basic trading signal simulation
- Easy-to-understand charts

## Insights
- Price movement shows variation over time  
- Trends can be identified through visual patterns  
- Helps in understanding market behavior at a basic level  

## Purpose
The goal of this project is to demonstrate how trading data can be analyzed and visualized using Python and interactive dashboards.
